How to use these icons

A — Paste an HTML snippet (fastest)

  1. Build your set on the Build a badge set tab.
  2. On Share & embed, copy the Paste-in HTML.
  3. In your course, create or edit an Item / Document, or open an assignment's Description.
  4. In the editor toolbar, open the source view — the <> button. In Ultra it's under the + / Insert / Edit HTML menu; in Original it's the HTML button.
  5. Paste, save, submit.
The snippet uses only inline styles and inline SVG — no external files, fonts, scripts, or links — so it passes Blackboard's HTML sanitizer on both Ultra and Original.

B — Share a link

  1. On Share & embed, copy the Student link.
  2. Paste it into an announcement, a syllabus, or the assignment's instructions.

The whole configuration travels inside the address, so nothing is stored on a server and the link never expires. Students see a clean, printable page — no builder controls.

C — Embed with an iframe

  1. Copy the embed code on Share & embed (either for your badge set or for the full icon guide).
  2. Paste it into Blackboard through the same <> source-code view used in option A.
Some Blackboard installations strip <iframe> from the HTML editor. If the embed disappears after saving, use Insert content → Embed (Ultra) or Build Content → Web Link with Open in new window off (Original) — or fall back to option A, which nothing strips.

D — Import the SCORM package

  1. Download um-integrity-icons-scorm.zip from the repository (do not unzip it).
  2. Original: Build Content → Content Package (SCORM). Ultra: + → Upload and choose the zip.
  3. Accept the defaults. It appears as an item students open in place.

E — Host the site yourself

  1. Upload this repository's contents to a GitHub repo, keeping index.html at the root.
  2. Settings → Pages, source = main branch, / (root), save.
  3. Your copy publishes at https://<username>.github.io/<repo>/, and every link and embed this page generates will point at it automatically.
